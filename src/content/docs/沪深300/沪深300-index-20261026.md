## 一句话结论

**持有，不加仓。** PE 12.61 倍落在 2011 年以来 46% 分位——不是便宜，是**中位数**。看起来便宜的只有利差：盈利收益率 7.93% 对 1.64% 的国债有 6.29 个百分点补偿，但这份补偿是国债利率塌出来的，不是盈利涨出来的：隐含盈利 322.24 点，比 2022 年 10 月的 333.53 点还低 3.4%。三档机械观察线——可定投 3873 点、加仓 3242 点、暂停 4679 点，现价 4062.69 在中间，两头都不挨。

## 一、累计倍数：二十年 4.40 倍，全收益 6.69 倍

价格指数，人民币，未含股息；全收益指数为 H00300，同一截止日。指数基日为 2004-12-31，本表用 2005 年最后一个交易日作「自基日」起点。

| 起点 | 价格倍数 | 价格年化 | 全收益倍数 | 全收益年化 |
|---|---|---|---|---|
| 2005-12-30 | 4.40 倍 | 7.4% | 6.69 倍 | 9.6% |
| 2011-10-31 | 1.51 倍 | 2.8% | 2.14 倍 | 5.2% |
| 2016-10-31 | 1.22 倍 | 2.0% | 1.55 倍 | 4.5% |
| 2020-07-31 | 0.87 倍 | -2.3% | 1.01 倍 | 0.2% |
| 2007-10-16（历史高点） | 0.69 倍 | -1.9% | 1.03 倍 | 0.1% |
| 2015-06-08（杠杆高点） | 0.76 倍 | -2.4% | 1.00 倍 | 0.0% |
| 2021-02-10（抱团高点） | 0.70 倍 | -6.1% | 0.82 倍 | -3.5% |

二十年 4.40 倍、年化 7.4%，不算难看；全收益 6.69 倍、9.6%，是合格的中国股票长期回报。**难看的在三个高点**：2007 年买进去，十九年价格 0.69 倍；2015 年买进去，十一年 0.76 倍；2021 年买进去，五年半全收益还亏 18%。指数不是不涨，每次涨完都要花十年还债——这是 A 股最稳定的规律，比任何一次「牛市起点」的叙事都稳定。

回撤同时摆出来，避免只看一个参照点：

| 参照点 | 点位 | 距现价 |
|---|---|---|
| 52 周最高（2026-06-22） | 5059.66 点 | -19.7% |
| 2015-06-08 高点 | 5353.75 点 | -24.1% |
| 2021-02-10 高点 | 5807.72 点 | -30.0% |
| 2007-10-16 高点 | 5877.20 点 | -30.9% |
| 52 周最低（2026-10-22） | 4036.30 点 | +0.7% |

现价离 52 周低点只有 0.7%，离 52 周高点 19.7%——**这半年是从 5059 点跌到 4036 点的下跌中继，不是高位横盘**。把「回撤 19.7%」当成「跌了很多」是错觉：它也只是把 2025 年 10 月的 4606 点跌回去，一年维度还是负收益。

## 二、三套口径：谁在说它便宜

| 口径 | 倍数 | 位置 | 用法 |
|---|---|---|---|
| 中证官网 PE（`peg` 字段，滚动） | 12.74 倍 | 2026-10-23 | **主口径**：与点位同源，逐日可回溯 |
| 蛋卷 PE / PB | 12.82 倍 / 1.36 倍 | 2026-10-23 | 交叉验证：与官网差 0.6%，可放心用 |
| 自建合成（东财动态 PE 市值加权调和） | 11.37 倍 | 2026-10-26 盘中 | 覆盖率 97.73%，**偏低**，只作下限参考 |
| 前瞻 PE | 缺口 | — | 拿不到 2027 年一致预期，本节不给 |

三个能拿到的口径落在 11.37 到 12.82 之间，分歧一成出头——不是口径之争，是分母的季报差异。自建口径偏低有两个机械原因：东财给的是最新单季年化的动态 PE，且剔除了 2.27%（=100−97.73）市值的负盈利成分，剩下的分母天然更乐观。**这一成多的带宽本身就是结论：沪深300 的估值分歧不在「贵不贵」，在「用哪一年的利润」**。前瞻口径缺，所以「便宜」这个词只能对历史说，不能对未来说。

## 三、跌的是利润，还是倍数

| 科目 | 数值 |
|---|---|
| 现价隐含 TTM 盈利（指数点） | 322.24 点 |
| 2016-10-31 隐含盈利 | 244.24 点 |
| 2022-10-31 隐含盈利（本轮峰值） | 333.53 点 |
| 近十年价格倍数 | 1.22 倍 |
| 近十年隐含盈利倍数 | 1.32 倍 |
| 近十年 PE 倍数 | 0.92 倍 |
| 隐含盈利相对 2022-10 峰值 | -3.4% |
| 2021-02 以来 PE 倍数 | 0.66 倍 |
| 2021-02 以来隐含盈利倍数 | 1.06 倍 |
| 52 周高点以来 PE 倍数 | 0.83 倍 |
| 52 周高点以来隐含盈利 | -3.5% |

十年：价格 1.22 倍 = 盈利 1.32 倍 × 倍数 0.92 倍。利润涨三成，倍数掉 8%，分红再加 2.49 个百分点/年，凑出全收益 4.5%。**这一段是「利润在涨、估值在压」的典型**，也是沪深300 被误读最多的地方——它长期回报不高不是经济没增长，是起点估值太高。

2021 年抱团高点以来：盈利 ×1.06、PE ×0.66。跌的几乎全是倍数，利润一分没少。但最近 52 周变成了另一种形态：PE ×0.83、盈利 -3.5%——**杀估值之外，分子也开始松了**。

最关键的一句：隐含盈利 322.24 点，对比 2022-10 的 333.53 点，四年零增长。上一轮是「利润在涨、股价不涨」，这一轮是利润本身也不涨。**盈利停滞的指数，12.6 倍不叫便宜，叫「该给的倍数」**。

## 四、利率：6.29 个点的补偿，是国债给的

| 指标 | 数值 |
|---|---|
| 盈利收益率（100 ÷ 12.61） | 7.93% |
| 中国 10 年期国债（2026-10-23） | 1.64% |
| 风险补偿（对国债） | 6.29 个百分点 |
| 美国 10 年期国债（2026-10-23） | 5.09% |
| 风险补偿（对美债） | 2.84 个百分点 |
| 股息率 | 3.03% |
| 股息率 − 国债收益率 | 1.39 个百分点 |
| 股息率 ÷ 国债收益率 | 1.85 倍 |

这是本报告最需要拆开看的一节。6.29 个百分点放在任何成熟市场都是「极便宜」的信号；对美债只有 2.84 个点，那才是「正常」。**同一条 12.61 倍的线，对着 1.64% 的国债是便宜，对着 5.09% 的美债是「还行」**——所以这个便宜是人民币利率给的，不是沪深300 的盈利能力给的。

反证很简单：用今天的国债利率去套 2024-01 的 PE 10.29 倍，补偿是 8.08 个百分点。也就是说，**PE 从 10.29 抬到 12.61（+22.5%），单这一项就把补偿从 8.08 压到 6.29——利率下行让出来的空间，被估值抬升吃得干干净净**。利率再往下空间有限，这条逻辑已经接近走完。

股息率 3.03% 是另一个视角：它是国债的 1.85 倍。对能拿十年的钱，分红本身就超过无风险收益——这是真实的支撑，但它支撑的是「拿得住」，不是「会涨」。

## 五、分位与极值：46% 分位不是便宜

| 指标 | 数值 |
|---|---|
| PE 历史分位（2011-06-28 起 3655 个交易日） | 46.2% |
| PB 历史分位（2016-07 起，蛋卷口径） | 26.8% |
| PE 历史中位数 | 12.81 倍 |
| PE 10% / 33% / 80% 分位 | 10.06 / 12.02 / 14.52 倍 |
| PE 历史最低（2014-05-19） | 8.55 倍 |
| PE 历史最高（2015-06-08） | 20.38 倍 |
| PE 分位 − PB 分位 | 24.9 个百分点 |
| ROE（PB ÷ PE） | 10.62% |

先说口径断档：中证官网的 PE 逐日序列从 2011-06-28 才开始，**2007 年那轮泡沫没有官方 PE 可算**，所以 46% 分位是「2011 年以来」的分位，不是「历史」的分位。这一点必须写在数字旁边，否则 46% 会被误读成「二十年的中位」。

再看 PE 与 PB 的 24.9 个百分点差：PE 分位在中间，PB 分位在下三分之一。这不是矛盾，是 ROE 掉到 10.62%（2016 年以来的低位区）的结果——**同样的 PE 对应更低的 PB，说明资本回报在下台阶，而不是资产变便宜**。低 PB 遇上低 ROE，不构成买入理由。

分位是相对自己的历史。绝对水平这一栏，12.61 倍既不便宜（要跌 20% 才够到 10.06 的 10% 分位），也不过热（要涨 15% 才够到 14.52 的 80% 分位）。

分层看很清楚：**前十里有七只是金融、能源、通信央企，唯一像成长的权重是宁德时代 1.70%**。前五只股票占了 20.59%，而它们的共同定价变量是利率、净息差、油价和分红率——不是景气度，不是技术周期。买沪深300 得到的是一个「高分红+利率敏感」的价值组合，不是「中国新经济」的组合。把它的 12.6 倍去比纳斯达克的三十几倍，是拿银行比软件，比出来的便宜没有意义。

权重口径要说明：这里是总市值加权，中证官方用自由流通市值加权并分级靠档，银行的官方权重会低于 25.53%，成长股会抬高一些。**但排序不会变**——工行、建行、农行仍在前五，结论不依赖这个近似。

## 七、区间与纪律：机械观察线，不是买入价

以 PE 分位为锚，分母（隐含盈利 322.24 点）不变，只换倍数：

| 触发条件 | 对应点位 | 距现价 |
|---|---|---|
| PE 8.55 倍（2014 极值） | 2755 点 | -32.2% |
| PE 10.06 倍（10% 分位） | 3242 点 | -20.2% |
| PE 12.02 倍（33% 分位） | 3873 点 | -4.7% |
| PE 14.52 倍（80% 分位） | 4679 点 | +15.2% |
| PE 8.55 倍且盈利再降 15% | 2342 点 | -42.4% |

- **暂停区间**：PE 14.52 倍以上，即 4679 点以上。现价离它还有 15.2%，没到。
- **可定投区间**：PE 12.02 倍一线，即 3873 点。现价高 4.7%，差一点，没到。
- **加仓触发**：PE 10.06 倍一线，即 3242 点，接近 2024-01 与 2022-10 的底部水平。
- **最坏情况**：PE 回到 8.55 倍且盈利再降 15%，2342 点，从现价再跌 42.4%。这不是预测，是压力测试的边界。

这五条线是机械观察线，随盈利和成分变化而移动，不是买入价，也不构成对内在价值的判断。若通过 ETF 实施，另看费率、跟踪误差、折溢价三件事，本报告不展开。

## 八、A 股特有的两个偏差：价格指数与总股本加权

**偏差一：这是一条不含分红的价格指数。** 所有关于「A 股十年不涨」的结论，都建立在一条把分红当空气的线上。

| 区间 | 价格倍数 | 全收益倍数 | 分红贡献（年化） |
|---|---|---|---|
| 近十年 | 1.22 倍 | 1.55 倍 | 2.49 个百分点 |
| 自 2005-12-30 | 4.40 倍 | 6.69 倍 | 2.18 个百分点 |

年化 1.99% 对 4.48%（近十年），差 2.49 个百分点，这就是股息的全部贡献。换算成体感：十年价格指数涨 22%，全收益涨 55%。**判断 A 股长期回报必须用全收益指数，用价格指数得出的「十年不涨」是错的；反过来，把 PE 和点位挂钩时只能用价格指数**——两条线各有各的用途，混用是最常见的错。

**偏差二：总股本加权下，金融与白酒决定了指数的形状。** 银行 25.53%、白酒 3.65%（其中茅台 2.60%）。这带来两个后果：

1. **指数的低 PE 有一半是行业结构给的**，不是估值给的。银行 PE 个位数，天然把整体拉低；这不是「市场先生悲观」，是加权法。
2. **指数的波动由 5 只股票决定**（前五 20.59%）。当银行涨、其余跌时，指数可以是涨的——「指数涨了我却亏钱」在沪深300 上不是错觉，是数学。

所以对这条指数做估值判断，真正要跟踪的是**净息差、长端利率、白酒的量价**这三件事，而不是 GDP 增速或新兴产业景气。它与「中国经济的成长性」的相关系数，比多数人以为的低得多。

## 九、反面论据与数据来源

**最强反对**：银行占 25.53%，净息差已经见底，2027 年银行利润修复 10% 就能把 12.61 倍摊薄成 11.5 倍——那时候回头看，现在就是底部，46% 分位只是「还没涨」。
**成立需要什么**：净息差连续两个季度回升、银行不良率不再上行、白酒（3.65%）的量价止跌，三者至少两样。
**现在有没有**：都没有。ROE 10.62% 处在 2016 年以来低位区，隐含盈利四年零增长，盈利端一个证伪信号都没出现。

其他反面：

- **口径断档**：中证 PE 序列 2011-06-28 才起，2007 年泡沫期只有价格没有 PE；2015 年的 20.38 倍是序列内最高，但它不是「史上最高」。跨断档画分位会系统性低估极端估值。
- **权重近似**：总市值口径把银行放大（自由流通加权会压低银行、抬高成长股），25.53% 是上限读数；结论只依赖排序，不依赖这个数的小数位。
- **盈利口径跳动**：隐含盈利 = 收盘 ÷ `peg`，中证 `peg` 是滚动口径，季报切换时会跳变。2024-01 的 312.47 点与 2022-10 的 333.53 点之间的落差含口径成分，不能全算作盈利下滑。
- **利率不可持续假设**：整篇的风险补偿都建立在 1.64% 的国债上。情景里若长端回到 3%，同样的 12.61 倍，补偿只剩 4.93 个百分点，结论要从「持有」下调。
